# AGENTS.md

Untuk setiap pekerjaan UI, teks, aksesibilitas, dan layout mobile pada repositori ini:
1. Baca `DESIGN.md` sebagai sumber arah visual, palet warna, tipografi, dan dial (`ENERGY 2 / RHYTHM 3 / MOTION 2`).
2. Gunakan aturan `antislop` sebagai filter wajib (tanpa em dash, kontras WCAG AA terukur, target sentuh minimal 44x44px, tiga state lengkap, dan verifikasi klik nyata).
